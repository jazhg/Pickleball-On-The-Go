IF IT DOES NOT CONNECT

Both devices must be on the same Wi-Fi. Use https:// and the laptop’s LAN IP, never localhost on the phone. If Safari says the connection is not private, install the public mkcert CA on the phone and enable full trust in Settings → General → About → Certificate Trust Settings.

Start the relay from the project folder with npm start. The terminal prints the exact phone URL.
