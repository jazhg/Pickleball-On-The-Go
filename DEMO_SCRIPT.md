# SteelHacks demo

Use the current [90-second demo and evidence guide](HACKATHON.md).

The important claims are: deterministic singles scoring, Nemotron choosing a
training action from rally evidence, and the selected action appearing in the
coaching/practice workflow. Only a `model` result is evidence of a live NVIDIA call.
The checked-in eight-case report is offline (7/8, zero human-reviewed cases).

Do not use the older claim that a model updates the score or that the provisional
standalone referee is a validated tournament referee. No live API evaluation was
possible without a key during this implementation session.
